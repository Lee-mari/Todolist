# Study Quest

쪼개서 하나씩 클리어하는 공부 스케줄러. 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있어요.

## 화면

| 탭 | 할 수 있는 것 |
| --- | --- |
| **오늘** | 오늘 공부한 시간, 다음 일정, 연속 공부 일수, 보드의 '하는 중' 카드, 오늘 시간표 |
| **이번 주** | 주간 목표와 진행률, 요일 선택, 요일별 시간표 추가/수정/삭제, 쉬는 시간, 쪼갠 할 일, 집중 타이머, 빈 시간 채우기, 하루 목표 |
| **공부 보드** | 할 일 / 하는 중 / 끝냄 칸반 (끌어서 옮기기), 과목별 진행도, 필터, 쪼갠 할 일, 숫자 목표(예: 단어 120/200), 매일 반복, 마감일 |
| **강의 노트** | 강의(과목) 등록, 회차별 4칸 정리 퀘스트 (한 줄 요약, 핵심 3개, 헷갈린 점, 다시 볼 부분), 자동 저장, 시간표 일정과 연결 |
| **공부 기록** | 하루 마감 퀘스트(어제 실제 공부 시간 기록), 주간 통계, 요일별 막대 그래프, 과목별 시간, 지난 주간 기록 |
| **설정** | 이름, 라이트/다크 테마, '하는 중' 최대 개수, 과목 관리(색·아이콘), 백업 내보내기/불러오기, 초기화 |

## 편의 기능

- 삭제하면 알림의 **되돌리기**로 바로 복구
- 시간표 수정: 지난주 같은 요일 가져오기, 다른 날로 복사, 평일에 복사, 전체 시간 밀기/당기기, 하루 비우기
- 일정 반복 추가 (이번 주 평일 / 매주 4·8·16주)
- 키보드 `n`으로 빠르게 추가, `Esc`로 닫기
- 휴대폰 화면에서는 하단 탭바로 바뀜

## 데이터

모든 데이터는 브라우저의 `localStorage`에 저장돼요. 다른 기기로 옮기려면 **설정 → 백업 파일 내보내기 / 불러오기**를 써 주세요.
처음 열면 예시 데이터가 채워져 있고, **설정 → 전부 지우고 새로 시작**으로 비울 수 있어요.

## 구조

```
js/sample.js     예시 데이터
js/schedule.js   오늘 / 이번 주

js/lectures.js   강의 노트
js/record.js     공부 기록
js/settings.js   설정
js/app.js        시작 & 이벤트 연결
```
