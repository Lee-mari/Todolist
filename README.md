# Study Quest

쪼개서 하나씩 클리어하는 공부 스케줄러. 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있어요.
배포 주소: https://lee-mari.github.io/Todolist/

## 편의 기능

- 삭제하면 알림의 **되돌리기**로 바로 복구
- 시간표 수정: 지난주 같은 요일 가져오기, 다른 날로 복사, 평일에 복사, 전체 시간 밀기/당기기, 하루 비우기
- 일정 반복 추가 (이번 주 평일 / 매주 4·8·16주)
- 영상 시간은 `32:10`, `1:02:03`, `32`(분), `1시간 5분`처럼 적으면 돼요
- 키보드 `n`으로 빠르게 추가, `Esc`로 닫기
- 휴대폰 화면에서는 하단 탭바로 바뀜

## 데이터

기본은 브라우저의 `localStorage`에 저장돼요. 처음 열면 예시 데이터가 채워져 있고, **설정 → 전부 지우고 새로 시작**으로 비울 수 있어요.

### 구글 로그인으로 휴대폰·PC 동기화 켜기 (Firebase, 무료)

`js/firebase-config.js`가 비어 있으면 동기화 없이 동작해요. 아래 순서로 한 번만 설정하면 설정 탭과 사이드바에 **구글로 로그인** 버튼이 생겨요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 돼요)
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → Google** 사용 설정
3. **Authentication → 설정 → 승인된 도메인**에 `lee-mari.github.io` 추가
4. **빌드 → Firestore Database → 데이터베이스 만들기** (프로덕션 모드, 위치 `asia-northeast3 (서울)`)
5. Firestore **규칙** 탭에 아래 내용을 붙여 넣고 **게시**

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }
   ```

6. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(`</>`) 앱 등록** 후 나오는 `firebaseConfig` 값을 `js/firebase-config.js`에 붙여 넣기

`firebaseConfig` 값은 공개되어도 괜찮아요. 각 사용자는 자기 데이터(`users/{uid}`)만 읽고 쓸 수 있도록 위 규칙이 막아 줘요.
처음 로그인한 기기에서는 "계정 데이터 불러오기 / 이 기기 데이터 올리기" 중 하나를 고르고, 그 뒤로는 바뀐 내용이 자동으로 다른 기기에 반영돼요.
